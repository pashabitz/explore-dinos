DINOSAUR SIZE COMPARISON SILHOUETTES

16 frames, each 512 x 512 RGBA, packed into a 2048 x 2048 PNG in 4 rows and 4 columns, no gaps.
First two rows follow set 1 order; last two rows follow set 2 order.
Each frame contains one dark-gray dinosaur and the same human silhouette at 1.75 m tall. Both stand on y=480.
Color #363636. Transparent background. No labels.
Frames are independently scaled for readability; compare each dinosaur to its own human, not to neighboring tiles.
Size comparisons are approximate educational illustrations, not scientific reconstructions. Length-based scaling uses illustrated horizontal extent; bent necks and tails introduce approximation. Brachiosaurus and Therizinosaurus use approximate total standing height instead. Every scale reference is recorded in JSON.
